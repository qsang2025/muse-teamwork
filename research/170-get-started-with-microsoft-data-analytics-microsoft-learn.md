## Khảo sát nhanh (sẽ mở rộng ở bản đầy đủ)

Learning path hiện hành gồm 4 module: (1) Explore the analytics process that turns data into insights — 5 loại analytics + 5 vai trò + chu trình 5 tác vụ prepare–model–visualize–analyze–manage; (2) Get started building with Power BI — Desktop/Service/Mobile, luồng 6 bước, semantic model + visuals, workspace/app/refresh; (3) Introduction to end-to-end analytics using Microsoft Fabric — OneLake, workloads, workspace, governance; (4) Get started with Copilot in Power BI — Copilot hỗ trợ chuẩn bị/mô hình/DAX/báo cáo, Prep data for AI (simplify schema, verified answers, AI instructions, Approved for Copilot).

Lưu ý khảo sát: mô tả cũ trên trang Power BI ("get, clean, and transform data by using Power Query") không khớp cấu trúc hiện hành — phần Get data / Clean-transform-load bằng Power Query nằm ở learning path kế tiếp "Prepare data for analysis with Power BI", không nằm trong path này. Bản đầy đủ sẽ đối chiếu 169 (thang mô tả–dự đoán–kê đơn), 168 (GA4), 144/145/147 (Microsoft Learn trước đó) và ranh giới FREE/Pro/Copilot capacity.
